# notes/: the workshop (not published)

Everything here is outside `docs/`, so MkDocs never publishes it. These are working files for whoever resumes the course (Grok Bot or John).

## Layout

```
notes/<category>/YYYY/MM/DD/NNN-slug-name.md
```

- `YYYY/MM/DD` is the date the file was created (America/Los_Angeles).
- `NNN` is a per-day, per-category sequence: 001, 002, …
- `slug-name` is lowercase ASCII with hyphens. **No macrons in paths**; macrons go inside the files.
- To revise a file, edit it in place. Start a new dated file when it's a new document or a new decision.
- `STATE.md` (top level) is the entry point: read it first.

## Categories

| Dir | Latin | Meaning | What goes here |
|---|---|---|---|
| `consilia/` | *cōnsilia* | plans, counsels | scope map, dependency order, judging rubric, book plans |
| `iudicia/` | *iūdicia* | judgments, verdicts | reviews from the judging rubric (L1/L2/L3 findings) |
| `acta/` | *ācta* | things done, records | session logs, grades, voice-chat results |
| `commentarii/` | *commentāriī* | notebooks, memoranda (cf. Caesar's) | working notes, drafts, scratch ideas |
