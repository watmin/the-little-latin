# Chapter 1: Salvē!

*In which we say hello, ask how things are, learn a name, and say goodbye. With snacks.*

## Hello

| Question | Answer |
|---|---|
| What is *salvē*? | A greeting. Hello. |
| Say it aloud. | *Salvē.* SAL-way. |
| Is the *ē* at the end short or long? | Long. The bar says so. Hold it. |
| Whom do you say *salvē* to? | One person. |
| Your friend Iūlia walks in. What do you say? | *Salvē, Iūlia!* |
| Your teacher walks in. In Latin a teacher is a *magister*. What do you say? | *Salvē, magister!* |
| A warm loaf of bread walks in. Bread is *pānis*. | *Salvē, pānis!* (Strange, but correct.) |
| Now Iūlia *and* the teacher walk in together. Is *salvē* still right? | Not quite. *Salvē* is for one. |
| What do you say to two or more people? | *Salvēte!* sal-WAY-teh. |
| What got added? | *-te* |
| What does *-te* seem to mean? | "You, more than one of you." |
| Iūlia, the teacher, and the bread all walk in. | *Salvēte!* |

## Goodbye

| Question | Answer |
|---|---|
| Iūlia is leaving. What is goodbye? | *Valē!* WAH-lay. |
| Why WAH and not VAH? | In classical Latin, **v** sounds like English **w**. |
| How long is the *ē* in *valē*? | Long, just like in *salvē*. |
| Iūlia and the teacher leave together. Guess. | *Valēte!* |
| How did you know? | *-te* for more than one. Just like *salvēte*. |
| Is that a coincidence? | No. |

!!! note "The First Law of *-te*"
    When you speak **to** a group, telling or wishing them something (*be well! be healthy!*), add **-te**.

    *salvē* → *salvēte* · *valē* → *valēte*

| Question | Answer |
|---|---|
| What does *salvē* literally mean? | "Be healthy!" It's a command. |
| And *valē*? | "Be strong! Be well!" Also a command. |
| So Romans greeted each other by... | ...ordering each other to be healthy. Very caring. Very bossy. |
| You're leaving a dinner party with ten guests. | *Valēte!* |
| You're leaving the leftover cheese. Cheese is *cāseus*, one cheese. | *Valē, cāsee!* Or, if you're too sad to grammar: just *Valē!* |

## How are you?

| Question | Answer |
|---|---|
| What is *quid agis?* | "How are you?" Literally, "What are you doing?" |
| Say it. | *Quid agis?* KWID AH-gis. |
| Is the *g* hard or soft? | Always hard, like *go*. |
| Is there any macron in *quid agis*? | No. Every vowel is short. Say it quick. |
| How do you answer if things are good? | *Bene, grātiās.* |
| What does *bene* mean? | Well. BEH-neh. |
| What does *grātiās* mean? | Thanks. GRAH-tee-ahs. |
| Which vowels are long in *grātiās*? | Both *ā*s. |
| Is it *grātis*? | No! *Grātīs* means "for free." Say *grātiās*: GRAH-tee-AHS. |
| Your friend asks *quid agis?* and you just ate a great pizza. | *Bene, grātiās!* |
| Want to ask back? "And you?" is *et tū?* | *Bene, grātiās. Et tū?* |
| Is the *ū* in *tū* long? | Yes. *too*, not *tuh*. |
| You ask a whole table how they are. Will *-te* work on *agis*? | No. *Agis* isn't a command. It's a question. |
| So what do you say to a group? | *Quid agitis?* |
| What changed? | *-s* became *-tis*. |
| Should you memorize that now? | Just notice it. We'll meet it again. |

## What's your name?

| Question | Answer |
|---|---|
| What is *quid est nōmen tibi?* | "What is your name?" |
| Word by word? | *quid* what, *est* is, *nōmen* name, *tibi* to you. |
| So literally? | "What is the name to you?" |
| Which vowel is long in *nōmen*? | The *ō*. NOH-men. |
| Have you seen *quid* before? | Yes, in *quid agis*. It means "what." |
| How do you answer? | *Nōmen mihi est John.* |
| Literally? | "The name to me is John." |
| What is *mihi*? | "To me." MIH-hee. |
| And *tibi*? | "To you." TIH-bee. |
| Can the words move around? | Yes. *Mihi nōmen est John* is fine too. Latin is relaxed about order. |
| A bread roll asks your name. | *Nōmen mihi est John.* |
| You ask the bread roll back. | *Quid est nōmen tibi?* |
| It says *Nōmen mihi est Pānis*. Is that surprising? | No. |

## How it sounds

!!! info "Classical pronunciation in four lines"
    - **c** is always hard, like *k*: *Cicerō* is KEE-ke-rō, never SIS-er-o or CHEE-che-ro.
    - **v** is *w*: *valē* is WAH-lay.
    - **g** is always hard: *agis* like *a-giss*, with *go*'s g.
    - **Long vowels** (ā ē ī ō ū ȳ) last about twice as long as short ones. Length can change meaning: *grātiās* (thanks) isn't *grātīs* (free).

| Question | Answer |
|---|---|
| How do you say *Cicerō*? | KEE-ke-rō. |
| Did the Church say it differently? | Yes, CHEE-che-ro. That's ecclesiastical. Here we stay classical. |
| Is vowel length just decoration? | No. It's part of the word. |

!!! warning "The Commandment"
    Never say a Latin word silently when you could say it aloud.

## Speak it aloud

Read each line aloud, slowly, then again at normal speed. Then do the whole dialogue.

1. *Salvē!* · *Salvēte!*
2. *Valē!* · *Valēte!*
3. *Quid agis?* · *Quid agitis?*
4. *Bene, grātiās. Et tū?*
5. *Quid est nōmen tibi?*
6. *Nōmen mihi est John.*

**Dialogue:**

> **A:** *Salvē!*
> **B:** *Salvē! Quid agis?*
> **A:** *Bene, grātiās. Et tū?*
> **B:** *Bene, grātiās. Quid est nōmen tibi?*
> **A:** *Nōmen mihi est John.*
> **B:** *Valē, John!*
> **A:** *Valē!*
