# Caput I: Salvē!

*Liber I, Prīma Verba · Chapter 1*

*In which we learn how Latin sounds, say hello and goodbye to one person and to many, ask how someone is, trade names, and survive our first Latin conversation. Snacks will be mentioned.*

!!! abstract "In this chapter"
    - **Sounds:** classical (restored) pronunciation: vowels, long vowels and macrons, diphthongs, consonants, stress (also called emphasis: the syllable you lean on)
    - **Saying:** *salvē / salvēte*, *avē / avēte*, *valē / valēte*, *quid agis? / quid agitis?*, *bene, grātiās*, *et tū?*, *quid est nōmen tibi?*, *nōmen mihi est…*
    - **Law:** the First Law of *-te*
    - **Classroom survival:** *iterum, quaesō*, *lentius, quaesō*, *nōn intellegō*
    - **Reading:** your first Latin dialogue
    - **Speaking:** a full greeting conversation, aloud

!!! tip "How to read this chapter"
    Each answer hides under a wax tablet. Answer each question **out loud** first, then tap the tablet to check. Wrong guesses are welcome; they're how the rules get into your head.

---

## 1. Sounds first

:: Prīmum audī, tum dīc. || First listen, then speak.

{#g-01}

| Question | Answer |
|---|---|
| Was Latin written before it was spoken? | No. Romans spoke it first, at dinner, in the street, at the baths. |
| So where do we begin? | With sounds. |
| Which pronunciation does this book use? | Classical, sometimes called *restored*: our best reconstruction of how educated Romans spoke in Cicero's time. |
| Is there another pronunciation? | Yes. Ecclesiastical (Church) Latin, which sounds more like Italian. It's lovely, but we won't use it here. |
| How many vowels does Latin have? | Five letters: **a e i o u** (plus **y** in Greek words). |
| How many vowel *sounds*? | Ten. Each vowel comes short or long. |
| What does "long" mean? | It lasts longer. Roughly twice as long. |
| Does a long vowel sound different from a short one? | A little. Mostly it's held longer. |
| How do we show a long vowel in writing? | With a bar on top called a **macron**: ā ē ī ō ū ȳ. |
| Did the Romans write macrons? | Usually not. Learners use them because length is part of the word. |
| Is length just decoration, then? | No. It can change the meaning. |
| *malum* vs. *mālum*? | *malum*, short a: "a bad thing." *mālum*, long ā: "an apple." |
| *liber* vs. *līber*? | *liber*: "a book." *līber*: "free." |
| So if you say *malum* when you mean *mālum*... | ...you've offered your friend something bad instead of an apple. |

!!! note "The Commandment of Length"
    A macron is part of the spelling. Learn it with the word, say it with the word, write it with the word.

### The vowels

{#g-02}

| Question | Answer |
|---|---|
| Short **a** sounds like… | the *a* in "ago" or a quick "ah." |
| Long **ā** sounds like… | the *a* in "father," held. |
| Short **e**? | Like *e* in "pet." |
| Long **ē**? | Like *ey* in "they," but pure, with no glide at the end. |
| Short **i**? | Like *i* in "sit." |
| Long **ī**? | Like *ee* in "machine." |
| Short **o**? | Like *o* in "for," quick. |
| Long **ō**? | Like *o* in "note," pure, with no "-oo" glide. |
| Short **u**? | Like *u* in "put." |
| Long **ū**? | Like *oo* in "food." |
| Say *mālum*. | MAH-lum. |
| Say *nōmen*. | NOH-men. |

### Two vowels, one sound

{#g-03}

| Question | Answer |
|---|---|
| What is a diphthong? | Two vowels sliding together into one syllable. |
| **ae** sounds like… | "eye." *Caesar* is KYE-sar. |
| **au** sounds like… | "ow" in "how." *aurum* (gold) is OW-rum. |
| **oe** sounds like… | "oy" in "boy." *poena* (penalty) is POY-na. |
| Are diphthongs long or short? | Always long, so they never need a macron. |
| Is *Caesar* SEE-zer, then? | Not in classical Latin. KYE-sar. |

### The consonants

{#g-04}

| Question | Answer |
|---|---|
| How is **c** pronounced? | Always hard, like **k**. |
| Even before e or i? | Even before e or i. *Cicerō* is KI-ke-rō. |
| What about Church Latin? | CHEE-che-rō. That's ecclesiastical. Not here. |
| How is **g** pronounced? | Always hard, like the *g* in "go." |
| How is **v** pronounced? | Like English **w**. *valē* is WAH-lay. |
| How is consonantal **i** pronounced? (Some books write it as j.) | Like English **y**. *Iūlia* is YOO-lee-a. |
| **qu**? | Like "kw." *quid* is KWID. |
| **s**? | Always hissed, as in "sit." Never a z sound. *rosa* is RO-sa. |
| **t**? | Always t. Never "sh" or "ts." |
| **r**? | Rolled or tapped, as in Spanish or Italian. |
| **x**? | "ks." *rēx* (king) is RAYKS. |
| **h**? | A light breath, as in "hat." |
| A doubled consonant, like the **nn** in *annus*? | Say it twice: an-nus, with a tiny hold. |
| How is **ph** pronounced? | A *p* with a puff of air, not *f*. Same for **th** and **ch**. Mostly in Greek words. |

### Where the stress falls

{#g-04a}

| Question | Answer |
|---|---|
| Say "a world record." Which part of *record* do you lean on? | REC-ord. |
| Now say "record a song." | re-CORD. |
| Same letters. What changed? | Which syllable you leaned on. |
| Did the meaning change? | Yes. REC-ord is a thing; re-CORD is something you do. |
| Say *banana* the normal way. | ba-NA-na. |
| Now say BA-na-na. | It sounds wrong. A little funny, even. |
| What does a leaned-on syllable sound like? | Louder and a bit longer. Often a little higher, too. |
| What is that lean called? | **Stress.** It's also called **emphasis** (your high-school teacher's word) or **accent**. Same idea. |
| How does this book mark stress? | With capital letters: SAL-vē puts the stress on SAL. |
| Where is the stress in PIZ-za? | On PIZ. |
| Does every Latin word of two or more syllables have a stressed syllable? | Yes, exactly one. |
| So the question is… | …which syllable gets the stress. Let's find out. |

{#g-05}

| Question | Answer |
|---|---|
| Does Latin stress the last syllable? | Almost never. |
| Then which one? | In a two-syllable word, the **first**: *SAL-vē*, *NŌ-men*, *BE-ne*. |
| And in longer words? | Look at the second-to-last syllable. |
| If it's long? | Stress it: *va-LĒ-te*, *sal-VĒ-te*. |
| If it's short? | Stress the one before it: *A-gi-tis*, *GRĀ-ti-ās*. |
| Must you memorize this now? | No. Just imitate the stresses given in this chapter. The full rule comes back later. |

## 2. Hello

:: Salvē, amīce! || Hello, friend!

{#g-06}

| Question | Answer |
|---|---|
| What is *salvē*? | A greeting. Hello. |
| Say it. | *SAL-wē.* |
| Is the *ē* long or short? | Long. Hold it. |
| Is the *v* a V or a W? | W. |
| Whom do you say *salvē* to? | One person. |
| Iūlia walks into the kitchen. | *Salvē, Iūlia!* |
| The teacher walks in. A male teacher is *magister*. | *Salvē, magister!* |
| A female teacher is *magistra*. | *Salvē, magistra!* |
| A warm loaf of bread walks in. Bread is *pānis*. | *Salvē, pānis!* (A strange kitchen, but good Latin.) |
| Iūlia greets you: *Salvē!* What do you answer? | *Salvē!* The answer to *salvē* is *salvē*. |
| Now Iūlia and the teacher walk in together. Is *salvē* still right? | Not quite. *Salvē* is for one person. |
| What do you say to two or more? | *Salvēte!* sal-WĒ-te. |
| What did we add? | *-te* |
| What does *-te* seem to mean? | "You, more than one of you." |
| Iūlia, the teacher, and the bread all walk in. | *Salvēte!* |
| What does *salvē* literally mean? | "Be well! Be healthy!" |
| So is *salvē* a command? | Yes. Romans greeted each other by ordering good health. |
| Is there another hello? | *Avē!* "Hail! Greetings!" |
| To a group? | *Avēte!* |
| How did you know? | Same trick: add *-te* for more than one. |

## 3. Goodbye

:: Valē et mē amā. || Goodbye, and love me. (Cicero's way to end a letter)

{#g-07}

| Question | Answer |
|---|---|
| Iūlia is leaving. Goodbye is *valē*. Say it. | *WAH-lē.* |
| What does *valē* literally mean? | "Be strong! Be well!" Another command. |
| Iūlia and the teacher leave together. | *Valēte!* |
| How did you know? | *-te* for more than one, again. |
| Is that a coincidence? | No. It's a law. |

!!! success "The First Law of *-te*"
    When you speak **to** more than one person and tell or wish them something (*be well! be healthy!*), add **-te**.

    | to one | to many |
    |---|---|
    | *salvē* | *salvēte* |
    | *avē* | *avēte* |
    | *valē* | *valēte* |

{#g-08}

| Question | Answer |
|---|---|
| You leave a dinner party with ten guests. | *Valēte!* |
| You leave one guest asleep on the couch. | *Valē!* |
| Two friends leave *you*. They say *valē*. What do you say back? | *Valēte!* There are two of them. |
| Does *-te* work on every word? | No. Only on words that tell someone to do something. We'll see many more in Chapter 6. |

## 4. How are you?

:: Sī valēs, bene est. || If you are well, it is good. (how Roman letters began)

{#g-09}

| Question | Answer |
|---|---|
| What is *quid agis?* | "How are you?" |
| Literally? | "What are you doing?" or "What are you up to?" |
| Say it. | *KWID A-gis?* |
| Are there any long vowels? | No. Every vowel in *quid agis* is short. |
| Is the *g* soft? | Never. Hard, as in "go." |
| What does *quid* mean by itself? | "What?" |
| How do you answer if things are good? | *Bene.* "Well." BE-ne. |
| And politely? | *Bene, grātiās.* "Well, thanks." |
| Say *grātiās*. | *GRĀ-ti-ās.* Both a's long. |
| Is it GRAH-shus? | No. A Latin **t** is always t. |
| Is it GRAH-tsee-ahs? | That's the Church way. Classical: GRĀ-ti-ās. |
| Is it *grātis*? | No! *Grātīs* means "for free." *Grātiās* means "thanks." |
| How do you tell them apart when speaking? | *GRĀ-ti-ās*: three syllables, ending in a long ās. *GRĀ-tīs*: two syllables, ending in a long īs. |
| Things are great. "Very well" is *optimē*. | *Optimē, grātiās!* |
| Things are fine. "Not bad" is *nōn male*. | *Nōn male.* |
| Things are bad. "Badly" is *male*. | *Male.* (Then we feed you.) |
| What is *nōn*? | "Not." The ō is long. |
| *Satis bene* means "well enough." Where on the scale? | Between *bene* and *nōn male*. Fine. |
| You just ate an excellent plate of pasta. *Quid agis?* | *Optimē, grātiās!* |
| You dropped the pasta. *Quid agis?* | *Male.* |
| You want to ask back: "And you?" | *Et tū?* |
| What is *et*? | "And." |
| What is *tū*? | "You." Long ū, like "too." |
| Put it together. | *Bene, grātiās. Et tū?* |
| You ask a whole table how they are. Will *-te* work on *agis*? | No. *Agis* isn't a command. It's a question. |
| Then what do you say to a group? | *Quid agitis?* A-gi-tis. |
| What changed? | *-s* became *-tis*. |
| Have you seen a *t* meaning "more than one of you" before? | Yes, in *-te*. |
| Should you memorize the pattern now? | Just notice it. It comes back in Chapter 5. |

!!! info "Scale of moods"
    *optimē* (very well) · *bene* (well) · *satis bene* (well enough) · *nōn male* (not bad) · *male* (badly)

## 5. What's your name?

:: Nōmen est ōmen. || A name is a sign.

{#g-10}

| Question | Answer |
|---|---|
| What is *quid est nōmen tibi?* | "What is your name?" |
| Word by word? | *quid* what · *est* is · *nōmen* name · *tibi* to you |
| So, literally? | "What is the name to you?" |
| Have you seen *quid* before? | Yes, in *quid agis*. |
| Which vowel is long in *nōmen*? | The ō. NŌ-men. |
| How do you answer? | *Nōmen mihi est John.* |
| Literally? | "The name to me is John." |
| What is *mihi*? | "To me." MI-hi, with a light h. |
| And *tibi*? | "To you." TI-bi. |
| Are *mihi* and *tibi* a pair? | Yes. *mihi* to me, *tibi* to you. Chapter 11 explains them. For now they're a chunk. |
| Can the words move around? | Yes. *Mihi nōmen est John* is just as good. Latin word order is flexible. |
| Is *quod nōmen tibi est?* also correct? | Yes. "What name is to you?" Same question, slightly different words. |
| A bread roll asks your name. | *Nōmen mihi est John.* |
| You ask the bread roll. | *Quid est nōmen tibi?* |
| It says *Nōmen mihi est Pānis*. Surprised? | No. |
| Someone tells you their name. You want to say "And mine is John." | *Et mihi nōmen est John.* |

## 6. Classroom survival

:: Hominēs, dum docent, discunt. || People learn while they teach. (Seneca)

{#g-11}

| Question | Answer |
|---|---|
| The teacher says something you missed. "Again, please." | *Iterum, quaesō.* |
| Say *quaesō*. | *KWAI-sō.* Remember: ae = "eye." |
| What does *quaesō* mean? | "Please" (literally, "I ask"). |
| The teacher talks too fast. "More slowly, please." | *Lentius, quaesō.* |
| You don't understand. | *Nōn intellegō.* |
| Who is that? | *Quis est?* *Quis* asks "who?", *quid* asks "what?" |
| You do understand. | *Intellegō!* |
| Someone helps you. "Thank you" (a fuller form). | *Grātiās tibi agō.* "I give thanks to you." |
| Have you seen *tibi* before? | Yes, in *quid est nōmen tibi?* |
| Have you seen *ag-* before? | In *quid agis?* The same verb, *agō*: "I do, I drive." With *grātiās* it means "I give (thanks)." |

## 7. Lectiō: Reading

:: Tolle, lege! || Pick it up and read! (Augustine)

Read the Latin aloud twice. Check yourself with the English, which starts under its wax tablet: tap **Ostende** to uncover it. Then hide the English again and read the Latin once more. To test yourself the other way, hide the Latin and rebuild it from the English.

::: cover lectio-la "Latīna · Latin" shown
> **Magistra:** Salvēte, discipulī!  
> **Discipulī:** Salvē, magistra!  
> **Magistra:** Quid agitis?  
> **Iūlia:** Optimē, grātiās.  
> **Quīntus:** Nōn male. Et tū, magistra?  
> **Magistra:** Bene, grātiās. *(to a new student)* Salvē! Quid est nōmen tibi?  
> **John:** Nōmen mihi est John.  
> **Magistra:** Quid agis, John?  
> **John:** Satis bene… nōn intellegō!  
> **Magistra:** Quid agis?  
> **John:** Lentius, quaesō!  
> **Magistra:** Quid… agis?  
> **John:** Ah! Bene, grātiās!  
> **Magistra:** Optimē. Valēte, discipulī!  
> **Omnēs:** Valē, magistra!  
:::

::: cover lectio-en "Anglicē · English" hidden
> **Teacher:** Hello, students!  
> **Students:** Hello, teacher!  
> **Teacher:** How are you (all)?  
> **Iūlia:** Very well, thanks.  
> **Quīntus:** Not bad. And you, teacher?  
> **Teacher:** Well, thanks. *(to a new student)* Hello! What's your name?  
> **John:** My name is John.  
> **Teacher:** How are you, John?  
> **John:** Well enough… I don't understand!  
> **Teacher:** How are you?  
> **John:** More slowly, please!  
> **Teacher:** How… are… you?  
> **John:** Ah! Well, thanks!  
> **Teacher:** Excellent. Goodbye, students!  
> **Everyone:** Goodbye, teacher!  
:::

{#g-12}

| Question | Answer |
|---|---|
| What is *discipulī*? | Students (more than one). Guess from context. |
| What is *omnēs*? | Everyone, all. |
| Why does the teacher say *salvēte* but the students say *salvē*? | She greets many; they greet one. |
| Why does John need *lentius, quaesō*? | She spoke too fast. |
| How is Quīntus? | *Nōn male.* Not bad. |

## 8. Pronunciation check

:: Verba volant. || Words fly. (So say them well.)

{#g-13}

| Question | Answer |
|---|---|
| *Cicerō*? | KI-ke-rō. |
| *Caesar*? | KYE-sar. |
| *valēte*? | wa-LĒ-te. |
| *Iūlia*? | YOO-li-a. |
| *grātiās* vs. *grātīs*? | GRĀ-ti-ās (thanks, three syllables) vs. GRĀ-tīs (free, two syllables). |
| *quaesō*? | KWAI-sō. |
| Did any of these use a soft c, a v sound, or "sh"? | No. Never in classical Latin. |

!!! warning "The Commandment of the Mouth"
    Never read Latin silently when you could read it aloud.

## Speak it aloud

:: Ōre, nōn oculīs. || With the mouth, not the eyes.

Say each line slowly, then at normal speed. Exaggerate the long vowels.

1. *Salvē! · Salvēte! · Avē! · Avēte!*
2. *Valē! · Valēte!*
3. *Quid agis? · Quid agitis?*
4. *Optimē · bene · satis bene · nōn male · male*
5. *Bene, grātiās. Et tū?*
6. *Quid est nōmen tibi? · Nōmen mihi est John.*
7. *Iterum, quaesō. · Lentius, quaesō. · Nōn intellegō.*
8. *Grātiās tibi agō.*
9. Minimal pairs: *grātiās / grātīs · malum / mālum · liber / līber*
10. Read the *Lectiō* aloud, playing every part.
