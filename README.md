# The Little Latin

A listening-and-speaking-first Latin book in the style of *The Little Schemer*: tiny question-and-answer steps, rules you discover yourself, classical pronunciation, macrons always.

Read it: https://watmin.github.io/the-little-latin/

Built with MkDocs Material; every push to `main` deploys via GitHub Actions. New chapters go in `docs/chapters/` and get added to `nav` in `mkdocs.yml`.
